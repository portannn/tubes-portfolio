# Tubes Portfolio — Vue 3

Interactive dark-aurora team portfolio built with **Vue 3** and **Vite**.

## Features

- **Welcome Screen**: Deep obsidian backdrop with smoky purple aurora glow, centered pill navbar (`About`, `Experience`, `Education`, `Projects`, `Skills`, `Contact`), spaced `WELCOME` hero, and `CLICK TO ENTER` button.
- **Select Your Character**: Clicking `CLICK TO ENTER` (or clicking the welcome screen) transitions smoothly to the **Select Your Character** page displaying **Dio**, **Fahmi**, **Triztan**, and **Seto**.
- **Individual Character Portfolios**: Selecting any character opens their personalized portfolio page with `About`, `Experience`, `Education`, `Projects`, `Skills`, `Certificates`, and `Contact` sections plus quick character switcher tabs.
- **Full-Page Detail Views**: Clicking `View Details` on any Experience, Project, or Certificate opens a dedicated full-page detail screen with structured sections and prev/next navigation.

## Getting Started

```bash
npm install
npm run dev
```

## Customization

Edit `src/data/characters.js` to update names, roles, bios, `avatarUrl`, experience, education, projects, skills, certificates, and contact links for each member.
